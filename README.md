# Cloud Maker — Управление виртуальными машинами на QEMU/KVM

Решение тестового задания по управлению виртуальными машинами на Linux-хосте (Fedora) с использованием QEMU/KVM и libvirt.

## Реализованный функционал (согласно заданию)
*   **Обязательное задание:** Создание и запуск ВМ через CLI (`virsh`, `virt-install`).
*   **Задание 1:** HTTP API на Python (FastAPI) для создания, остановки и удаления ВМ.
*   **Задание 2:** Автоматическая конфигурация ВМ при запуске через `cloud-init` (передача `user-data`, `meta-data`, SSH-ключей и hostname).
*   **Задание 3:** Создание виртуальной сети `host-bridge`, работающей через сетевой мост `br0` хоста.
*   **Задание 11:** Скрипт автоматической проверки всех фич `check_features.sh`.
